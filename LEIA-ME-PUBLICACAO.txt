AquaGuard completo 1.8.1

1. Substitua os arquivos no repositório mantendo as pastas.
2. Preserve as variáveis de ambiente da Render, principalmente DATABASE_URL e JWT_SECRET. Build: npm ci. Start: npm start. Faça o deploy.
3. As tabelas e o campo local_admin_id são criados automaticamente na inicialização. Não execute os scripts limpar_*.sql para atualizar.
4. Acesse /usuarios como administrador geral. Edite cada usuário comum, escolha o Administrador Local responsável e selecione os locais autorizados. Salve.

ATENÇÃO: os usuários comuns existentes precisam receber o vínculo para acessar os dados após esta atualização. Não há associação automática. Se o responsável for desativado ou deixar de ter acesso a um local, o usuário perde o acesso correspondente, mesmo com uma sessão aberta.

O administrador geral mantém acesso global. Itinerários do administrador local ficam limitados a ele e seus usuários vinculados, sempre respeitando os locais associados. O cadastro de usuários permanece exclusivo do administrador geral. O vínculo não transfere locais nem altera contratos.

Inclui controle de mensalidades, ícones para instalação no celular, SQLs, Worker Cloudflare e site de divulgação em site/. Dependências serão instaladas por npm ci. Não contém senhas de produção ou dados do Neon. Veja README.md para demais instruções.
